# Product Images Folder

## Add Your Product Images Here!

This folder contains organized subfolders for all your product images.

### Folder Structure:
```
products/
├── chairs/
│   ├── mesh-chair/          ← Add mesh chair images
│   ├── leather-chair/       ← Add leather chair images
│   ├── recliners/           ← Add recliner images
│   └── gaming-chair/        ← Add gaming chair images
├── tables/
│   ├── bed-table/
│   ├── folding-table/
│   ├── sit-stand-table/
│   ├── height-adjustable-table/
│   ├── training-table/
│   ├── executive-table/
│   ├── study-table/
│   ├── director-table/
│   ├── workstation/
│   └── round-square-table/
└── accessories/
    ├── ergonomic-footrest/
    ├── cable-tray/
    ├── monitor-stand/
    ├── cup-holder/
    └── desk-mat/
```

### How to Use:
1. Place images in the appropriate subfolder
2. Use JPG, PNG, or WebP format
3. Keep file size under 500KB
4. Name files descriptively (e.g., `mesh-chair-1.jpg`)

### Reference in Code:
```
/images/products/chairs/mesh-chair/your-image.jpg
```

For complete instructions, see: `PRODUCT_IMAGES_GUIDE.md` in the project root.
